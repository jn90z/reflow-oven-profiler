# GUI and analysis roadmap

Windows-first Python app (PySide6 or browser UI) with optional Raspberry Pi deployment.

- Device discovery/connection and live 8-channel visualization.
- Run settings: oven ID, Heller 1809 MK7 zone setpoints, conveyor speed, PCB/assembly name, paste limits.
- Profile metrics and pass/fail limits; CSV/PDF report export.
- Session storage, missing-sequence reconciliation, calibration and run comparison.
- Physics-informed, data-calibrated recipe simulator and optimization proposals.
- Offline test mode using synthetic fixture datasets.

Predictions require measured training/validation runs and are never a substitute for a measured production profile.
