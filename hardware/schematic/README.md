# DipTrace Rev A — schematic work package

This directory contains a **logical connectivity draft**, not a checked netlist generated by DipTrace. Pin numbers and some connections remain unverified.

## Sheets
- 01 ESP32-S3-WROOM-1U-N8 / USB / reset / boot
- 02 MAX31856 thermocouple channels 1–4
- 03 MAX31856 thermocouple channels 5–8
- 04 SPI NOR data storage and bench 3.3V supply

## Import workflow
Use `netlist-revA.csv` as a human-readable connection checklist. It is **not** a DipTrace importable netlist. Create and validate schematic symbols from manufacturer datasheets, place each component, connect named nets, and run ERC. Do not copy symbolic pin names as physical pin numbers.

## Critical open issues
1. MAX31856 BIAS/FAULT/DRDY wiring and exact input filtering from official datasheet.
2. Thermocouple alloy transition location and CJC error.
